Types of Websites

Understanding the different types of websites and how they work

Introduction

There are different ways to classify websites depending on how they work, how they are managed, and what they are used for.

Important: Static and dynamic describe how a website works, while CMS and e-commerce describe how a website is managed or what it is used for.

This means that these categories can overlap. For example, an e-commerce website can also be a dynamic website and can be built using a CMS.

1. Static Websites

A static website displays mostly fixed content. The content is usually written directly into the website's HTML files.

Static websites are commonly built using HTML and CSS, with JavaScript added when interactive features are needed.

Examples

  • Personal portfolio website
  • Business landing page
  • Restaurant information website
  • School information website

Key Characteristic

The content does not normally change automatically based on users or information stored in a database.

Think of it this way:
A static website is like a printed brochure on the internet. The information stays mostly the same until a developer changes the files.

2. Dynamic Websites

A dynamic website can generate or change content based on user actions, databases, authentication, APIs, or other server-side processes.

Unlike a basic static website, a dynamic website can respond differently depending on the user or the information available in a database.

Technologies Commonly Used

  • JavaScript
  • React
  • Node.js
  • Express.js
  • PHP
  • Python
  • MongoDB
  • MySQL

Examples

  • Social media platforms
  • Job portals
  • Online banking platforms
  • Student portals
  • Job application trackers

Key Characteristic

Content and functionality can change dynamically based on users, data, or other conditions.

Example:
When you log into a student portal, you see your own courses, results, profile, and other information. Another student may see completely different information.

3. CMS Websites

CMS means Content Management System.

A CMS allows users to create, edit, organize, and publish website content without necessarily writing code for every change.

Examples of CMS Platforms

  • WordPress
  • Joomla
  • Drupal

Example

Imagine a company has a blog with hundreds of articles. Instead of asking a developer to manually edit the HTML every time a new article needs to be published, an employee can log into the CMS dashboard and create a new post.

Key Characteristic

Website content is managed through an administrative interface, often called a dashboard.

Think of it this way:
A CMS gives non-developers a way to manage website content without needing to edit the website's source code every time.

4. E-commerce Websites

An e-commerce website is a website designed to allow people or businesses to buy and sell products or services online.

Common Features

  • Product listings
  • Product search and filtering
  • Shopping cart
  • Checkout
  • Payment integration
  • Customer accounts
  • Order management
  • Inventory management

Examples

  • Amazon
  • Jumia
  • Online fashion stores
  • Online electronics stores
  • Shopify stores

Key Characteristic

An e-commerce website supports online commercial transactions.

Example:
A customer can browse products, add a product to a shopping cart, enter their details, make a payment, and receive an order confirmation.

Comparing the Four Types

Type Main Idea Example
Static Mostly fixed information Portfolio website
Dynamic Content or functionality changes based on users or data Job portal
CMS Content is managed through a content management system WordPress blog
E-commerce Designed for buying and selling products or services Online store

Can a Website Belong to More Than One Category?

Yes!

These categories are not completely separate from one another. A single website can fit into more than one category.

Example: A WordPress online store can be:

  • A CMS website because it uses WordPress.
  • An e-commerce website because it sells products.
  • A dynamic website because products, users, orders, and other data can change.

So, when identifying a website, ask two questions:

  1. How does the website work?
    Is it static or dynamic?
  2. What is the website used for or how is it managed?
    Is it a CMS, e-commerce website, blog, portfolio, educational platform, etc.?
